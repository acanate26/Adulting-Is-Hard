ADULTING IS HARD 

Your Grown-Up CheckList. A small static website with checklists for the stuff nobody teaches you, styled like a 90s personal homepage (inspired by Cameron's World).

It's plain HTML, CSS, and JavaScript. There's nothing to install and no build step.

🗂️File	What it is
index.html	Landing page: marquee, topic boxes, Click Here button, fake visitor counter, sparkle cursor trail
click.html	The chaos page: fake loading bar, random tip machine, confetti
protect_your_mental_health.html	Mental health checklist (calm look)
budget.html	Budget checklist (calm look)
laundry.html	Laundry checklist
cooking.html	Cooking checklist
sched_appoint.html	Scheduling appointments checklist
style.css	Shared styling for the five topic pages
script.js	Shared checklist behavior for the five topic pages
